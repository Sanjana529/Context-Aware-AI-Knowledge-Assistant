# Context-Aware AI Knowledge Assistant

A Streamlit-based AI knowledge assistant that allows users to interact with PDF documents using AI-powered question answering.

## Features

- PDF document upload
- Context-aware question answering
- AI-powered document search
- Flashcard generation
- Google Gemini integration
- Streamlit interface

## Technologies

- Python
- Streamlit
- Google Gemini
- ChromaDB
- PyPDF
- Scikit-learn

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
